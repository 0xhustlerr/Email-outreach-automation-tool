# Placement test sends are not outreach

A Placement test's emails go through sendMail directly, never performSend, so they write nothing to send_log, the Google Sheet, or any Sequence. The test email is a real Opener rendered with neutral contact values, sent from a Sender to Seed inboxes that are our own mailboxes (or a seed service's), not prospects. Logging them as sends would make each seed address a "contact" under ADR-0003, count toward Insights' sent and reply rates, and show up in History. We keep the single sendMail choke point, so NEXT_PUBLIC_SEND_DISABLED still blocks every test send, and the Signature and sender placeholders are applied exactly as they are for real outreach. Consequences: test sends do not count toward the queue's daily caps or the Sender rotation, so a Spam check run spends a little of a Sender's real daily budget that the Send plan cannot see, which is why tests only start by hand and one-to-one seeds stay few. Reply sync matches inbound mail only against send_log contacts, so a test copy landing in another Sender's inbox is never mistaken for a reply. Results are collected when the Spam check page reads them, not by a background loop (ADR-0002).
